## What this is

The personal portfolio of **Faizan Tanwar**: full-stack developer (MERN + TypeScript), Smart India Hackathon 2025 National Finalist, and final-year Computer Engineering student.

It's built like a tiny operating system. Every section is a window, the cursor leaves pixels behind, and the whole thing is meant to be poked at, not just scrolled.

## Try these

| Do this | Get this |
|---|---|
| Wait for the boot sequence | A 1.4-second startup, once per session, with a skip button |
| Move your mouse around the hero | The pixel-art character's eyes follow you |
| Click the character | It jumps, confetti pixels burst, and it says something |
| Hover over the character | It waves |
| Click `>_` in the nav | A working terminal: `help`, `about`, `projects`, `skills`, `contact` |
| Click any featured project | A details window (press `Esc` to close) |
| Scroll | A pixel loading bar in the nav fills up as you go |
| Hover buttons and cards | Magnetic buttons, tilting cards, windows that lift and glow |

## Built with care for

- **Performance:** transforms and opacity for motion, no heavy 3D, no large particle systems
- **Accessibility:** keyboard-friendly navigation and modals, visible focus states, and `prefers-reduced-motion` support that turns the motion down
- **Mobile:** windows stack into a single column, cursor effects switch off on touch devices
- **Honesty:** every project, number and link on the site is real
